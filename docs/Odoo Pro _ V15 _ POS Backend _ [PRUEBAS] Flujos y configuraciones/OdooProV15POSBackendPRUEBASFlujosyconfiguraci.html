  • Confirmation of the delivered quantities

  • FLUJOS DE VENTA
  • Apertura de caja con control de caja

 Al realizar una apertura de caja control es darle un clic en apertura de balance le sale un pop up para completar los campos según la cantidad de billetes que se está realizando la apertura de la caja.

  • Ventas de productos sin stock

Luego de realizar la apertura se le da a crear pedido, se ingresa la venta correspondiente y se confirma la cotización.

Una vez creado el pedido y el cliente está listo para pagar se le da click a facturar. Luego de esto le saldrá un pop up para ingresa el o los métodos de pago y se le da un clic a crear factura

NOTA: Esto es por el campo  de Confirmation of the delivered quantities el caso de uso de la funcionalidad está correcto pero para aquellos clientes que no entreguen sus productos al instante no aplica. Esta prueba no se pudo completar porque el campo Confirmation of the delivered quantities esta obligatorio y no deja guardar las configuraciones de a caja sino esta el booleano encendido

  • Flujo de ventas de productos con stock y múltiples pagos.

Luego de crear el pedido se procede a realizar los pagos múltiples

Luego de darle agregar factura en el pop up que surge donde dice diario se agrega el método de pago que estará pagando. El sistema al ingresar en el primer método de pago un monto x al agregar el segundo pago el computa la diferencia a pagar

Luego que se le dé a crear y ver factura en el pie de la factura encontrar los pagos conciliados a la factura r

Y como se puede ver acá el conduce sacó del almacén los productos vendidos

  • Flujo de reembolso de  efectivo.

Para realizar el reembolso se tiene que ir al pedido y en la parte superior darle un clic a reembolso, luego le saldrá un pop up en este se debe de poner el motivo de reembolso y especificar qué método reembolso y la cantidad de los productos o servicios a reembolsar.

Aquí podrán ver la factura rectificativa generada y los asientos contables realizados.

Este es el asiento generado de la devolución del dinero

Acá se puede ver el conduce de retorno del producto que el cliente devolvió

  • Flujo de reembolso de producto

Para realizar el reembolso se tiene que ir al pedido y en la parte superior darle un clic a reembolso, luego le saldrá un pop up en este se debe de poner el motivo de reembolso y  la cantidad de los productos

Aquí podrán ver la factura rectificativa generada y los asientos contables realizados.

Acá se puede ver el conduce de retorno del producto que el cliente devolvió
